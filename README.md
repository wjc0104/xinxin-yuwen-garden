# 欣语

给欣欣的语文备课手记。

按七到九年级课文找视频、读原作者的讲解与教学资料，学习时随手划重点、记笔记。

- 六册目录，198 个条目；保留 627 个具体视频分集、198 份离线备课提纲及原有笔记关联
- 198 条目录各有可读外部文字，共 336 条；其中试讲稿 16 条、覆盖 11 课，尚未齐全；[逐课覆盖与缺项](docs/revision-005/text-coverage.md) 区分课文解读、教学设计、试讲稿等
- “刷新本课资料”实际联网查询匹配视频和 B站专栏；结果与失败状态如实显示，不保证每次都有新增
- 搜索按课文汇总，可筛视频、试讲稿和提纲；系统播放器支持全屏、横屏、六档倍速与时间点笔记
- 中文课表支持临时调课与每周调整；Bark 自动定时服务仍未部署、未配置

**iPhone · iOS 15.0+ · arm64 TrollStore · 0.0.5（build 5）**

欣欣的 iOS 15 手机为主要使用设备，开发者用 iOS 16.3 测试。Windows 本地检查不代表这两台真机或最终 IPA 已验收；最终构建、真实播放与界面验证见[验证记录](docs/TESTING.md)。

在私有仓库 [wjc0104/xinxin-yuwen-garden 的 Actions](https://github.com/wjc0104/xinxin-yuwen-garden/actions/workflows/build-ipa.yml) 对应成功运行下载 **XinxinGarden-TrollStore**，解压安装 `Xinyu-v0.0.5.ipa`。安装新版前建议导出学习备份并覆盖更新。

视频与外部文字来自原平台，接口、登录要求和阅读限制可能变化，未逐一完整观看或审定。备课提纲是练习参考，不是逐字试讲稿。九下保留过渡目录，实际篇目请对照学校用书。
