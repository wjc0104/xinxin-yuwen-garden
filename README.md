XR 陪你备课，iPhone 16 的系统日历负责提醒上课。🌼

## 花园里长了什么 🌱

| 一块小花圃 | 首版可以做的事 |
| --- | --- |
| 课文目录 | 七上到九下，按单元和原课号排列；198 个课文与课外诵读条目；合篇的具体篇名可搜索 |
| 找资料 | 搜本机课文、作者、资料与笔记；带课名打开 B 站、全网、国家平台限定搜索及教案搜索 |
| 十分钟试讲 | 教资／教招搜索方向；《春》原创试讲练习、《岳阳楼记》备课卡，以及少量明确来源的原站资源 |
| 小重点 | 文字选中划重点、PDF 文字高亮、个人备注、视频时间点、课文收藏；笔记可编辑和返回资料 |
| 文件口袋 | 从“文件”导入 PDF、UTF-8 TXT／MD 和 MP4／MOV／M4V；本地视频支持按书签跳转 |
| 上课小铃铛 | 已核对的 16 节周课表、按日期查看、单次调课／停课、长期调课、撤销记录；作文连堂保留休息 |
| 给 16 的提醒 | XR 经明确授权写入专用账户日历，16 使用同账号 iCloud 系统日历接收提醒 |
| 收好小花 | 本地原子保存；导出含附件的 JSON 备份，合并导入时保留本机同编号内容 |

外部搜索打开真实平台的搜索页面，不是假装已经抓取全网结果。外站视频使用原平台播放器，时间点手动填写；本地视频可以自动记下当前时间。扫描版 PDF 没有文字层时，需要手动写备注，首版不含 OCR。

## 先带回 XR 📱

到本仓库 [Releases](../../releases) 下载 `XinxinGarden-v0.1.0.ipa`，在 XR 上分享给 TrollStore 安装。详细步骤见 [安装与两台手机提醒](docs/INSTALL.md)。仓库为私有，下载需要你的 GitHub 账号访问权限。

目标为 **iOS 15.0+、arm64**，按你提供的 XR／可能为 15.4.1 准备。IPA 使用 ad-hoc 签名供 TrollStore 重新签名安装，不需要付费开发者证书。**真实 XR 安装、权限弹窗和 16 收到提醒的效果仍需拿到手机后验证**；模拟器通过不等于真机已验证。

## 给主力机的小纸条 🔔

1. 在“我的”设置本学期起止日期，勾选已核对后保存。默认日期只是占位。
2. XR 与 iPhone 16 开启同一 Apple ID 的 iCloud 日历。
3. 在课表点“同步到日历”，允许访问，选择正确的 iCloud 账户，创建专用日历。
4. 到 16 的系统日历确认小花园日历已勾选、课程时间正确，日历通知已允许。
5. 临时调课后在 XR 修改，再主动同步一次。若检测到系统日历中的外部修改，会先列出来，等你核对。

XR 只知道已写入账户日历，无法确认 16 是否已收到。首次同步或断网可能延迟；已到达 16 的事件由其系统日历负责提醒。应用不会发短信、聊天消息，也不会把手机闹钟当作日历同步。

精选入门链接、教材依据和权限参考均列于 [来源清单](docs/SOURCES.md)。原创练习不是官方教案或考试真题，不依据搜索热度宣称“必考”。当地教招要求请以萧县当年正式公告为准。

## 小花园的约定 🤍

- 免费资料优先，来源写清楚，收费内容明确标注。
- 「重点练习」有理由，「历年考过」有出处。
- 不搬运整本教材，不下载或破解第三方平台的视频。
- 只有你点「连接日历」才申请权限；笔记和备课资料留在设备里。
- 教材版次逐册核对，暂缺资料诚实地写「待补充」。

## 给以后继续浇水的人 🛠️

首版自主开发原生 SwiftUI 应用，系统 PDFKit／AVKit／EventKit 负责文档、视频和日历。没有引入整套在线教学平台或自建服务器，适合一位老师在旧设备上离线备课和保存个人资料。构建工具使用 [XcodeGen](https://github.com/yonaskolb/XcodeGen)，不把它算作课文／搜索功能。

```sh
swift test
python3 scripts/check-catalog.py
brew install xcodegen
xcodegen generate
# 使用 Xcode 打开 XinxinGarden.xcodeproj；或运行仓库 Actions。
```

仓库的 `Build TrollStore IPA` 工作流在 macOS 上构建 iOS 真机包、ad-hoc 签名并检查最低版本和 arm64，产出 IPA、SHA-256 与包验证报告。`iOS Smoke Tests` 运行模拟器流程测试并导出截图。
