# 欣语

给欣欣的语文备课手记。

按七到九年级课文找视频、看备课提纲，学习时随手划重点、记笔记。

- 六册目录，198 个条目；内置 668 个视频分集与逐课备课提纲
- 视频直接选看，文字提纲离线阅读；收藏、笔记保存在本机
- 中文课表，支持临时调课与每周调整
- Bark 跨手机通知；自动上课提醒需另行配置在线定时服务

**iPhone XR · iOS 15+ · TrollStore · 0.0.2**

在 [Actions](../../actions/workflows/build-ipa.yml) 的成功运行中下载 **XinxinGarden-TrollStore**，解压后安装 IPA。安装新版前建议在“我的”导出备份，不要先卸载旧版。

视频来自原平台，已核对分集标题与时长，尚未逐一完整观看；登录、清晰度和可用性由平台决定。提纲为欣语编写的练习参考。九下保留过渡目录，实际篇目请对照学校用书。
