# 欣语

给欣欣的语文备课手记。

按七到九年级课文找视频、看备课提纲，学习时随手划重点、记笔记。

- 六册目录，198 个条目；内置 627 个视频分集与逐课备课提纲
- 系统播放器直接看视频，下方随手记笔记、标时间点；文字提纲离线阅读
- 中文课表，支持临时调课与每周调整
- Bark 跨手机通知；自动上课提醒需另行配置在线定时服务

**iPhone XR · iOS 15+ · TrollStore · 0.0.4**

0.0.4 改用苹果系统播放器，显示实际画质；“边看边记”直接展开视频下方的笔记框，自动记下时间，草稿留在本机。点已存笔记的时间可回看。正文长按选词后，点底部“划重点”保存。

在 [Actions](../../actions/workflows/build-ipa.yml) 的成功运行中下载 **XinxinGarden-TrollStore**，解压后安装 IPA。安装新版前建议在“我的”导出备份，不要先卸载旧版。

视频来自原平台，按公开接口实际提供的清晰度播放，部分为 720P，部分只有低清；接口失效时可重试或打开原视频。已核对分集标题与时长，尚未逐一完整观看。提纲为欣语编写的练习参考。九下保留过渡目录，实际篇目请对照学校用书。
