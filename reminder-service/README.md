# 欣语上课提醒服务

XR 编辑课表，在线服务按课前 60 分钟向 iPhone 16 的 Bark 发通知。配置完成后，XR 和电脑都可关机。当前仓库只提供服务源码，**没有替用户部署或启用**。

## 先试接收手机

1. 在 iPhone 16 从 App Store 安装 [Bark](https://apps.apple.com/cn/app/id1403753865)，允许通知。
2. 把 Bark 首页显示的完整地址复制到 XR“我的 → 上课提醒”。
3. 保存，点“发送测试通知”，在 iPhone 16 确认收到。接收手机的密钥不要发到公开仓库。

Bark 当前要求 iOS 15.0 或更高。XR 的欣语负责发送，无需另外安装 Bark。相同 Apple ID 不是必要条件。

## 以后部署（需要 Cloudflare 账号）

在本目录运行：

```sh
npm ci
npx wrangler login
npx wrangler secret put PAIRING_TOKEN
npm run deploy
```

PAIRING_TOKEN 请用密码管理器生成至少 32 位随机字母、数字、下划线或短横线。不要提交到代码或截图里。每个服务实例只接收一份私人课表，切勿共用密钥。

将部署得到的 HTTPS 域名与令牌组合成连接：

```text
https://你的服务.workers.dev#你的令牌
```

在欣语“上课提醒 → 连接定时服务”粘贴连接，先确认学期起止日期，再点启用。成功后页面显示安排的提醒次数。调课后联网自动替换；更新失败会显示待更新，需点“更新提醒”。调课若未成功上传，服务仍按旧课表通知。

只支持官方 api.day.app 作为自动发送端点；自建 Bark 地址可测试发送，但不进入自动队列。更换手机前先停用，再修改地址。停用须收到服务成功确认。

## 时效与维护

使用 Durable Objects SQLite 存储和 Alarm。没有固定开机电脑；账号套餐、费用和服务限制以 Cloudflare 为准。Bark 走苹果推送，不保证秒级到达；勿当成必须响铃的系统闹钟。

- 作文连堂只在首节前提醒，中间仍保留 15 分钟休息。
- 请求带递增修订号，迟到的旧请求不能覆盖新调课或停用。
- 发送失败一分钟后重试；晚于计划五分钟或已经上课的通知丢弃，避免误导。
- 成功记录防止常规重复；极端网络超时下可能重复推送。
- 不记录推送密钥到日志；服务器存储包含接收密钥与提醒内容，停用后清空队列。

本地检查：`npm test`；部署打包检查：`npm run check`。真实云环境和 iPhone 接收仍需配置后实测。
