# 欣语网页版 · 本地开发检查点

这不是已完成的在线安装版。已实现受限同源媒体模块和 HTML `video` 系统控件，**生产身份适配、部署、浏览器真实帧与 Safari 真机仍待验收**。没有第三方 iframe/播放器，不将来源链接当成播放完成。

## 本机运行（无依赖安装）

从仓库根目录运行，Node.js 24 已验证：

```powershell
& 'C:\Program Files\node.exe' web/scripts/export-data.mjs
& 'C:\Program Files\node.exe' --test web/tests/*.test.mjs
& 'C:\Program Files\node.exe' web/scripts/serve.mjs
```

最后一项仅监听 `127.0.0.1:4173`，按 Ctrl+C 停止。它不是生产托管、身份验证服务，也不能让其他设备访问。修改任何 `dist/` 应用文件或源课程数据后必须重新导出，以更新 `version.js`；不要直接用 `file://` 打开页面。

此静态预览服务器不挂载媒体接口；视频会明确报告未接通，不开放本地测试身份到生产。

## 服务端媒体接入契约

- `server/media.mjs` 导出 `createMediaHandler({resources, fetchImpl, authorize})`。服务端从原始 `App/Resources/library.json` 读取受信资源（包含 `videoCID`），不能用客户端 catalogue 或请求构造白名单。模块只复制解析需要的字段。
- 平台适配器必须对每次请求调用真实身份校验，`authorize(request)` 仅严格返回 `true` 才允许；省略、异常或其他值均返回 401。不能用查询串、浏览器自报 header 或测试开关替代平台身份。
- `GET /api/video/:resourceID` 返回 `{resourceID, streamURL, quality, height, duration, page}`；`streamURL` 只可能是同源 `/api/video/:resourceID/stream`。第二个接口流式转发 MP4，支持单范围 `Range`。拒绝 URL 参数、不在白名单的 ID、跨源 Origin、多范围与异常路径。
- 只请求固定的公开 pagelist/playurl 接口，按原 library CID 精确查找，不按旧页码改播其他集。拒绝收费标记、预览、多段、非 MP4，若上游提供单段长度则校验与总时长一致。不发送用户 Cookie/Authorization，不解锁登录或付费资源。
- 媒体来源限定 HTTPS/443、`bilivideo.com` 主机边界及精确 `upos-hz-mirrorakam.akamaized.net`，每次手动重定向重验，最多 3 次。仅用公开原视频 Referer 与固定 UA；不返回 locator、上游 Cookie、Location 或 CORS。
- `video/mp4` 按媒体类型接收；`application/octet-stream` 必须额外探测 `bytes=0-4095`，验证完整且不超过 4096 字节的首个 `ftyp` 盒及 MP4 品牌，非零 seek 也验证零起始前缀。探测流随后取消，绝不整段下载后转码。它是容器识别，不是完整解码/画面验收。
- JSON 上限 1 MiB；默认等待上游 fetch/read 上限 20 秒、解析与探测总上限 60 秒。取消/超时关闭上游流。每次 fetch/read 返回后立即清除等待计时器，不把下游暂停/背压当作上游超时；流式传输不会强制 60 秒结束。实际长度与声明不符时报流错误。
- 平台适配器须原样转交 `Request.signal`、`Range` 和响应 body，不缓冲整段视频、不日志记录上游 locator。生产访问控制、并发/用量限制和真实 CDN 可达性由部署验收检查。

## 已实现的基础代码

- 四个入口：主页、课程、课表、我的。读取 6 册、198 课的稳定 ID 和原始顺序，搜索按课名精确匹配、作者、篇目、相关结果排序，中文输入组合完成后再过滤。
- `App/Resources/catalog.json` / `library.json` 是源数据；导出脚本显式挑选公开字段，不读取本机笔记、课表、原生备份。仅“欣语备课提纲”和“欣语原创练习”的自编正文进入网页，第三方正文留空。
- 自编正文使用文本节点呈现，重点有文字位置、资料 ID、来源和笔记关联。视频页采用原生控件与 `playsinline`，提供 0.5/0.75/1/1.25/1.5/2 六档倍速、全屏入口、读取当前时间、保存时间笔记和跳转；失败可重试并保留位置与草稿。导航取消旧请求、暂停并清空旧媒体，异步返回有世代校验。
- 收藏、笔记、空白起步的每周课表和日期调整保存在本机 IndexedDB。版本比较避免不同标签页相互覆盖；事务完成前不报告保存成功。读取失败不会用空数据覆盖旧记录。
- 独立网页备份 `format: xinyu-web`、`schemaVersion: 1`，最多 2 MB；紧凑 JSON 导出与导入容量一致，避免合法接近上限的记录因美化空白而无法回导。先校验完整结构、重复 ID、来源关联、URL 和重点位置，再原子替换。不兼容原生 App 备份。
- Manifest、同源静态资源缓存、手动检查发布数据版本；更新不强制刷新当前页面，也不清除 IndexedDB。

## 隐私、发布和缓存边界

- **仅所有者私有测试**。`web/.openai/hosting.json` 是既有站点身份配置，保留不改。不能据此宣称站点存在、部署成功或女朋友可访问；不得重新建站、开放匿名访问或邀请其他人。
- 后续发布审计包可含 `web/dist/`、受限媒体模块及显式字段白名单的公开服务端视频索引；不能把父仓库、完整原生源代码、个人数据、日志或凭据推送到托管。本次没有发布。
- 媒体后端只处理收录视频，不上传私人笔记、课表或收藏，不发送提醒；显示“提醒未启用”。不同设备/浏览器间不自动同步。
- 离线缓存只包含公开应用外壳、目录及自编文字。固定同源白名单排除 API、登录地址、查询串、第三方视频和全文；拒绝登录 HTML、重定向、错误状态和错误类型。检查更新使用 `no-store`，离线不能假报有新资料。
- 缓存不是身份验证。已缓存的公开资料及本机笔记可能在断网时仍可访问；不要在共享设备上存放私人记录。网站数据不加密，清理 Safari/系统回收数据可能丢失记录，请先导出并妥善保管私人备份。
- 首次使用必须联网，只有安装缓存成功后才具备离线基础。旧页面全部关闭后新版 SW 才能接管；不自动中断编辑。课程来源/正文变更导致旧笔记校验失败时会暂停写入，尚无自动迁移工具，勿清理旧数据。
