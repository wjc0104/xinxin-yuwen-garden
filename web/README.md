# 欣语网页版 · 本地开发检查点

这不是已完成的在线安装版。**视频仍未接通**，没有第三方 iframe/播放器；后续只能接入验证过的媒体并使用 HTML `video` 系统控件。目前不创建空播放器伪装可播放，也不将来源链接当成完成。

## 本机运行（无依赖安装）

从仓库根目录运行，Node.js 24 已验证：

```powershell
& 'C:\Program Files\node.exe' web/scripts/export-data.mjs
& 'C:\Program Files\node.exe' --test web/tests/*.test.mjs
& 'C:\Program Files\node.exe' web/scripts/serve.mjs
```

最后一项仅监听 `127.0.0.1:4173`，按 Ctrl+C 停止。它不是生产托管、身份验证服务，也不能让其他设备访问。修改任何 `dist/` 应用文件或源课程数据后必须重新导出，以更新 `version.js`；不要直接用 `file://` 打开页面。

## 已实现的基础代码

- 四个入口：主页、课程、课表、我的。读取 6 册、198 课的稳定 ID 和原始顺序，搜索按课名精确匹配、作者、篇目、相关结果排序，中文输入组合完成后再过滤。
- `App/Resources/catalog.json` / `library.json` 是源数据；导出脚本显式挑选公开字段，不读取本机笔记、课表、原生备份。仅“欣语备课提纲”和“欣语原创练习”的自编正文进入网页，第三方正文留空。
- 自编正文使用文本节点呈现，重点有文字位置、资料 ID、来源和笔记关联。视频页只允许手动记录时间；目前无自动进度读取/跳转。
- 收藏、笔记、空白起步的每周课表和日期调整保存在本机 IndexedDB。版本比较避免不同标签页相互覆盖；事务完成前不报告保存成功。读取失败不会用空数据覆盖旧记录。
- 独立网页备份 `format: xinyu-web`、`schemaVersion: 1`，最多 2 MB；先校验完整结构、重复 ID、来源关联、URL 和重点位置，再原子替换。不兼容原生 App 备份。
- Manifest、同源静态资源缓存、手动检查发布数据版本；更新不强制刷新当前页面，也不清除 IndexedDB。

## 隐私、发布和缓存边界

- **仅所有者私有测试**。`web/.openai/hosting.json` 是既有站点身份配置，保留不改。不能据此宣称站点存在、部署成功或女朋友可访问；不得重新建站、开放匿名访问或邀请其他人。
- 后续发布审计包仅限 `web/dist/`，不能把父仓库、个人数据、原生源代码、日志或凭据推送到托管。当前未发布任何链接。
- 网页没有后端，不上传私人笔记、课表或收藏，不发送提醒；显示“提醒未启用”。不同设备/浏览器间不自动同步。
- 离线缓存只包含公开应用外壳、目录及自编文字。固定同源白名单排除 API、登录地址、查询串、第三方视频和全文；拒绝登录 HTML、重定向、错误状态和错误类型。检查更新使用 `no-store`，离线不能假报有新资料。
- 缓存不是身份验证。已缓存的公开资料及本机笔记可能在断网时仍可访问；不要在共享设备上存放私人记录。网站数据不加密，清理 Safari/系统回收数据可能丢失记录，请先导出并妥善保管私人备份。
- 首次使用必须联网，只有安装缓存成功后才具备离线基础。旧页面全部关闭后新版 SW 才能接管；不自动中断编辑。课程来源/正文变更导致旧笔记校验失败时会暂停写入，尚无自动迁移工具，勿清理旧数据。
