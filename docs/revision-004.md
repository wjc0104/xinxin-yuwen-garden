# 0.0.4 · 系统播放与边看边记

## 实际问题

旧版“边看边记”只是文字标签，不能点击；底部写笔记会打开覆盖视频的弹窗。网页播放器中的时间也不能可靠读取。

先增加真实点击测试，[39598658677](https://github.com/wm0104/xinxin-yuwen-garden/actions/runs/39598658677) 在“可见入口必须是按钮”处失败，证明测试覆盖到了问题。

## 修改

- 按具体 BV 和分集查询公开播放源，使用 Apple AVPlayer 和 VideoPlayer，保留声音；不再把网页放进视频区域。
- 显示源的实际画质，并以视频轨尺寸复核。未登录样本可到 720P；部分示范视频只返回 360P，明确提示低清，不标成 1080P。
- “边看边记”在视频下方展开输入框，自动带入当前时间；可手填、取当前时间、保存或收起。键盘展开时缩小播放器，保留观看空间。
- 草稿文字与时间一起留在本机，收起、重新打开和重启都不改写时间。仅成功保存后清空；草稿不在学习备份内。
- 保存的时间点可在当前播放器回看；普通界面刷新保留同一播放器及播放位置，离开页面暂停。
- 临时地址不落盘；连接失败或超时后可重试，重新取源。不读取网页登录状态，不接入解析中转站。

## 验证范围

首轮 [39600461125](https://github.com/wm0104/xinxin-yuwen-garden/actions/runs/39600461125) 通过真实联网 AVPlayer 测试：对应第 2 集、720P、音轨存在、完整时长、播放时钟推进及 03:25 定位，并通过笔记保存等 UI 测试。此轮 ARM 云模拟器截图视频区域偏绿，因此不能仅凭时钟推进声称画面验证完成。
