# 0.0.5 · 可更新资料、课文搜索与全屏学习

课程页搜索本机目录和已有资料；进入课文后点“联网查找本课资料”，可真实查询本课视频和 B站公开专栏，并在应用内添加匹配的具体资料。空结果、部分失败与未新增分别提示，已有资料和笔记不因刷新失败而清除。合集视频按具体分集与稳定 CID 匹配；分集移动保留原资料 ID，原 CID 消失则失败，避免播到另一课。

搜索按课文汇总资料和笔记，课文名先于正文命中；支持清空和分类筛选。原生播放器使用同一 AVPlayer 进入/退出全屏，支持竖屏、左右横屏及六档速度：0.5、0.75、1、1.25、1.5、2 倍。系统静音开关、声音与实际画面仍需真机验收。

七至九年级全部 198 条目录均纳入[公开文字覆盖核对](revision-005/text-coverage.md)。阅读具体原文可摘录选区和记笔记；只打包元数据，不复制他人文章全文。教学设计、解读、说课与试讲稿分别标记，原有 198 份离线备课提纲仍是练习提纲，不冒充逐字稿。未找到、受阻和未搜索如实保留。

最低目标 iOS 15.0、arm64、TrollStore，bundle ID 保持 `com.wm0104.xinxingarden`。安装包名为 `Xinyu-v0.0.5.ipa`，build 为 5。仓库现为私有的 `wjc0104/xinxin-yuwen-garden`，旧链接可能重定向。

Bark 自动定时服务仍未部署、未配置；没有恢复日历同步。欣欣的 iOS 15 手机为主要设备，开发者用 iOS 16.3 测试。最终 Swift/iOS 测试、真实音画截图及精确 IPA 检查由最终提交的 CI 和真机验证提供，本地 Windows 检查不能替代。
