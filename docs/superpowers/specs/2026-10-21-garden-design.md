# 欣欣的语文小花园 · 首版设计 🌷

## 为谁而做
给欣欣准备初中语文教资面试、安徽萧县／黄口镇教师招聘面试，也照顾日常上课。
XR 安装完整 App；同一 Apple ID 的 iPhone 16 只使用系统日历提醒。

## 必须遵守
- 原生 iOS，最低 iOS 15.0，arm64；交付 TrollStore 可安装的 IPA。
- 私有仓库 wm0104/xinxin-yuwen-garden。描述、README 和界面温柔可爱，但信息准确。
- 六册按七上、七下、八上、八下、九上、九下和教材课号顺序，不以推荐分数重新排序。
- 安徽 2026–2027 学年统编人教教材为核对目标；逐册记录官方版次、来源和核对状态，不能编造最新版已齐全。
- 教资、教招都需要；优先免费，付费资源明显标注。来源开放，不伪称聚合搜索 API 已接通。
- 知识考点和官方证实的考试频率严格区分，未核实的频率不能标成必考。
- 文字可选择、高亮并备注；视频可保存原链接及时间书签。原平台视频在原网页播放，本地导入视频可用系统播放器；不下载或破解第三方视频。
- 备份导入不能破坏已有数据，不能把本机日历关联导入另一台设备。

## 页面与功能
1. 目录：六册卡片、单元／课文、有资料／待补充；每课含重点提示、原创试讲练习框架、收录资料、视频链接、个人重点。
2. 搜索：本地课文／资料／备注搜索；公开平台搜索入口预填「课名＋初中语文＋教资／教招＋10分钟试讲」，显示原来源而非伪造站内结果。可手动加入外部资料链接。
3. 重点本：按课文筛选高亮、个人备注、视频时间点；能编辑、删除并返回对应课文。
4. 课表：常规周表、按日期查看；单次调课、单次停课、从指定日期起改长期课表；允许单次撤销。作文连堂两节仍独立保留时间和 15 分钟休息，可整体平移。
5. 我的：本地备份／恢复、版本说明、来源说明、权限说明；学期起止和提醒分钟必须让使用者确认后才写入日历。

## 权限与同步边界
- 日历仅在「连接／同步课表」点击后请求。iOS 15–16 使用 requestAccess；iOS 17+ 使用 full access。
- 系统日历授权范围较大，App 的写入／删除只作用于用户选择账户后新建的「欣欣的上课小铃铛」专用日历。不可按日历名称就接管已有日历。
- 显示账户名称，推荐 iCloud；本地／其他账户明确不能保证同步到 16。权限拒绝、撤销、日历删除后，不允许无提示退回本地日历。
- 单次日期实例物化为独立事件，保留来源标记、event ID 和课表键，避免重复。只删除确认属于本 App 的过时事件；不触碰手动添加的事件。
- 从系统日历读到时间变化时提供导入调整；不在启动时自动覆盖手机 16 上的变动。
- 只显示「已写入该账户日历」，不可宣称 XR 可以确认 16 已经收到了提醒。
- 无联系人、定位、麦克风、相册或后台常驻权限。文件通过系统选择器主动导入；无埋点和自建服务器。

## 首版范围与证据
可以收录官方目录元数据、明确来源的外链和自行撰写的练习框架，不搬运整本教材或收费教案。
必须如实显示资料覆盖情况。原生 UI、日历权限／提醒的真实设备表现另需 XR 和 16 实测。
测试重点为顺序、搜索编码、重复同步、调课和停课、连堂休息、备份导入原子性、外链校验和笔记持久化。
