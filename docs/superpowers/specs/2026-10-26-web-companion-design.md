# 欣语免签网页版：设计提案

状态：待用户确认网页版与原生版差异；尚未开始产品实现或部署。

## 目的与已有基线

用户没有 Apple 开发者账号或签名材料，希望女朋友在 iPhone 16 Pro Max / iOS 26.0、iPad Pro 11 英寸第四代 / iPadOS 18.7.8 上通过链接使用欣语。本方案是 Safari 添加到主屏幕的 Web App，不是免签安装原生 IPA，不要求巨魔商店、描述文件或设备注册。

保留现有 iOS 15 / TrollStore 产品和测试。原生当前本地基线为 32b1ed82a86a773f440c826c2c6267f67d09f335；古文岛响应式排版改动已提交但原生最终 CI 未完成。网页不得以功能对照或静态测试替代原生验收。现有全部代码保留，不回退，不承诺 Swift 修复能直接在浏览器执行。

## 首版交互

- 四个中文入口：主页、课程、课表、我的。沿用欣语简洁配色，不用花草比喻、开发术语或个人设备信息。
- 六册课文按现有顺序排列。复用 App/Resources/catalog.json 与 library.json 的公开课程、资料元数据和稳定 ID，不打包私人笔记、课表、密钥、截图或录屏。
- 课文详情直接列出已经整理的具体视频与文字资料，而不是把搜索页当成资源。搜索优先课名精确匹配和作者匹配；模糊结果单独明确显示。
- 本仓库自编正文在网页内阅读，可选中文字保存重点和笔记。资料关联、文字位置、来源链接随笔记保存；不存在的试讲稿不以提纲冒充。
- 视频尝试明确支持网页播放的具体原站嵌入；合法可用直链使用 HTML video，支持平台允许的全屏、倍速和时间点笔记。第三方 iframe 无法可靠取得时间时允许手动填写时间，不假装自动记录。不解锁平台权限，不保证所有来源可嵌入或高清。
- 外部文章仅在来源允许时在应用内阅读；若跨站或嵌入限制阻止阅读，如实提示并提供具体原文链接。不能复用 WKWebView 的 UA/DOM 注入能力，不把“古文岛全文直接展开”标为网页版已实现。
- 课表用中文时间与班级，可本机增删、临时调整。不得公开女朋友实际课程；首次使用无个人课表。
- 本机收藏、笔记与自建课表持久化，支持导出、导入独立网页备份。新建明确 schemaVersion，不宣称与原生附件备份兼容。第一版不做跨设备自动同步。
- “添加到主屏幕”提供 iPhone/iPad 的图文操作说明；不伪造系统自动安装弹窗，不要求安装证书或描述文件。

## 明确限制和非目标

- 现有视频直链解析、联网找资料、古文岛全文阅读均必须先验证浏览器可行性；不能通过泛用开放代理、虚假新结果或静态刷新动画伪装成功。
- 首版刷新仅检查网站发布的数据版本，确有更新才提示新增；不冒充联网搜到了新视频。用户若要求与原生联网搜索等价，需要单独设计并验证服务端来源接入。
- 网页关闭后不依靠 JS 计时器承诺提前一小时提醒。Bark 后端尚未配置，默认明确显示“提醒未启用”。不发送真实通知，不公开 Bark key，不以本地 Toast 冒充通知。
- 网页可缓存应用外壳、自编文字和目录；不下载/离线缓存第三方全文或视频。系统清理网站数据会影响本机记录，因此提供显眼的备份入口。
- 不替换原生项目、不改原生播放器测试门槛、不自动发布 main、不执行关机。

## 技术选择（助手建议）

独立 web/ 边界，轻量 HTML/CSS/JavaScript、manifest、service worker、IndexedDB。资产尽量同源，不导入庞大 UI 框架。网站通过 HTTPS 托管；按 Sites 支持流程处理构建与发布，只有公开课程及自编资料可放入发布包。新 Site 默认私有，在用户确认女朋友可访问的共享范围后再选择实际发布权限；不得将所有者私有登录链接当成她可直接使用的最终地址。

原生仓库数据为唯一课程源，生成脚本只做公开字段白名单导出。主站、原生分开构建；更新 service worker 时不得清除 IndexedDB，不强制刷新正在编辑的笔记。

## 验收与交付顺序

1. 先以真实已收录视频、外部文字做有限浏览器兼容性验证；记录哪些能内嵌，哪些只能访问原文。若核心来源全部只能跳转，报告限制，不把目录壳当作完成版本。
2. 实现目录、精确搜索、自编文本阅读、重点、笔记、备份，使用现有所有课程，不只做示例两课。
3. 验证空结果、中文组合输入、恶意导入、无网、存储失败、刷新保留笔记；外链只允许 http/https，正文和笔记不执行 HTML。
4. 验证 iPhone/iPad 竖横屏布局、播放受限状态、笔记关联和恢复。桌面浏览器检查不冒充两台 Safari 真机验收。
5. HTTPS 部署并检查资源和 manifest/service worker 路径；提供实际链接与添加到主屏幕步骤，再请用户在两台设备验收。原生 IPA 修复、审查与 CI 仍单独进行。

## 需要用户确认的一项取舍

无签名网页版可实现桌面入口和本机学习资料管理，但不能承诺与现有原生版的第三方视频/古文岛阅读能力完全相同。确认此区别后再进入实现计划；不将“在线安装”理解为绕开苹果原生签名。
