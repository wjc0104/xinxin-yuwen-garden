# 私有网页系统视频接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development task-by-task.

**Goal:** 使用欣语 HTML video 控件播放经真实验证的已收录具体视频，不嵌入第三方播放器。
**Architecture:** 私有 Sites 服务端受限接入，仅接受已收录 resource ID，按现有原生策略解析精确 CID 与完整单段 MP4；流式转发合法公开媒体到同源 video。浏览器不接触上游带签名 URL。保留 owner-private，不做匿名代理。
**Tech Stack:** 平台 Fetch/Request/Response, plain JS modules, Node test; 后续部署通过 Sites 支持的 Vinext 服务端适配器。
**Spec:** docs/superpowers/specs/2026-10-26-web-companion-design.md，最新用户不使用 B站播放器界面。

## Global Constraints
- 不使用 cookies、登录令牌、付费解锁，不保证1080P。上游真实响应质量为准。
- 仅白名单资源 ID，不接收用户 URL。精确已知 CID 与分集匹配，缺失报错不改播其他集。
- 默认无部署身份则拒绝；测试身份仅由本地隔离测试服务器注入，不暴露生产绕过参数。
- 不持久化上游 locator、凭证，不日志输出它们。HTML video 同源请求；SW不缓存API或媒体。
- 不改 Swift；不关机；额度<=5%保存暂停。

## Review Focus
- URL混淆/恶意重定向/多范围/无效ID不能形成SSRF或开放代理。
- 精确CID、预览、多段、非MP4必须拒绝，不能悄悄替换视频。
- 中断/超时/客户端取消关闭上游流；响应不能误传Set-Cookie/位置/机密URL。
- 原站限流/不可用UI清晰，不称高清，保留笔记和重试前播放位置。
- 切课/导航后旧请求与媒体必须清理，时间点笔记必须来自当前媒体。
