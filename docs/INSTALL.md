# 安装欣语

1. 在本仓库 [Build TrollStore IPA](../../actions/workflows/build-ipa.yml) 选择最新成功运行。
2. 在 Artifacts 下载 **XinxinGarden-TrollStore**，解压得到 `Xinyu-v0.0.3.ipa`。
3. 将 IPA 保存到 XR“文件”，分享给 TrollStore 或在 TrollStore 点加号安装。
4. 已有旧版请先在“我的”导出备份，再覆盖更新；不要先卸载。

最低目标 iOS 15.0、arm64、iPhone。实际系统与 [TrollStore 官方兼容范围](https://github.com/opa334/TrollStore) 请在手机上核对。应用包只增加自身标识和专属 Keychain 存储组，不加入 JIT、调试或取消沙盒权限。

## 学习

“课程”按册和单元排列。点课文后直接选具体视频或文字提纲；可按类型筛选，也能搜索作者、课文和教学重点。文字可长按划重点；视频下方“标记时间·写笔记”。播放器无法读取时间时可手动填写，如 03:25。外部视频由原平台提供，可能要求登录；点击“打开原视频”也是对应分集，不是搜索页。

文字提纲可离线使用；视频和封面需联网。正文中长按选词，点底部“划重点”直接保存黄色高亮；“写笔记”用于补充想法。个人文件放在右上角“更多”中导入，不必为内置课程自行寻找链接。

## 课表和提醒

课表上方选择日期或星期。点课程可选“仅这一次”或“以后每周”，修改日期时间或停课。作文可两节一起移动，中间保留 15 分钟休息。调课记录可撤销。

在“我的 → 学期设置”核对起止日期，默认课前一小时提醒。iPhone 16 安装 Bark、允许通知，再把接收地址粘贴到 XR“上课提醒”，先发送测试通知。

**自动定时服务当前未部署**，因此只有主动测试通知可用。后续按 [提醒配置](../reminder-service/README.md) 接入即可；无需更换 IPA，也不依赖两台手机相同 Apple ID。启用后调课需联网更新成功，未更新时仍按旧安排；停用也需联网确认。卸载应用不会撤销服务器里的提醒。

旧版日历提醒在“我的”可主动扫描清除，仅处理原专用日历中带应用标记的事件。保留恢复标记，便于日历延迟同步后再次清理。请在 iPhone 16 核对旧事件已经消失。
