# 安装欣语

1. 在本仓库 [Build TrollStore IPA](../../actions/workflows/build-ipa.yml) 选择最新成功运行。
2. 在 Artifacts 下载 **XinxinGarden-TrollStore**，解压得到 `Xinyu-v0.0.5.ipa`。
3. 将 IPA 保存到 XR“文件”，分享给 TrollStore 或在 TrollStore 点加号安装。
4. 已有旧版请先在“我的”导出备份，再覆盖更新；不要先卸载。

0.0.5（build 5）最低目标 iOS 15.0、arm64、iPhone。欣欣的 iOS 15 手机为主要设备，开发者用 iOS 16.3 测试；最终版本仍需在真机验收。实际系统与 [TrollStore 官方兼容范围](https://github.com/opa334/TrollStore) 请在手机上核对。应用包只增加自身标识和专属 Keychain 存储组，不加入 JIT、调试或取消沙盒权限。

## 学习

“课程”按册和单元排列。点课文后直接选具体视频、公开文字或备课提纲；可按类型筛选，搜索结果按课文汇总。下拉或点“刷新本课资料”会联网查询匹配视频与 B站专栏，保留原有资料；受限或没有新结果时会明确提示。视频使用苹果系统播放器，显示视频源实际画质。可全屏、旋转横屏，并选 0.5、0.75、1、1.25、1.5、2 倍速；退出全屏后接着看、记笔记。点“边看边记”在视频下方写笔记，自动带入当前时间，也可手动填写，如 03:25；收起、切出或重启仍保留草稿。保存后点“回看”跳转到对应时间。“原视频”才会打开原站对应分集。

备课提纲可离线使用；外部文字、视频和封面需联网。外部文字在应用内打开具体原文，可选词摘录和写笔记，遵循原站阅读与选区限制。提纲不算完整试讲稿，逐课公开文字与试讲稿缺项见[覆盖报告](revision-005/text-coverage.md)。正文中长按选词，点底部“划重点”直接保存黄色高亮；“写笔记”用于补充想法。个人文件放在右上角“更多”中导入，不必为内置课程自行寻找链接。

## 课表和提醒

课表上方选择日期或星期。点课程可选“仅这一次”或“以后每周”，修改日期时间或停课。作文可两节一起移动，中间保留 15 分钟休息。调课记录可撤销。

在“我的 → 学期设置”核对起止日期，默认课前一小时提醒。iPhone 16 安装 Bark、允许通知，再把接收地址粘贴到 XR“上课提醒”，先发送测试通知。

**自动定时服务当前未部署**，因此只有主动测试通知可用。后续按 [提醒配置](../reminder-service/README.md) 接入即可；无需更换 IPA，也不依赖两台手机相同 Apple ID。启用后调课需联网更新成功，未更新时仍按旧安排；停用也需联网确认。卸载应用不会撤销服务器里的提醒。

旧版日历提醒在“我的”可主动扫描清除，仅处理原专用日历中带应用标记的事件。保留恢复标记，便于日历延迟同步后再次清理。请在 iPhone 16 核对旧事件已经消失。
