# 隐私与权限

课文收藏、学习笔记、导入文件和课表保存在本机。未保存的视频笔记草稿也保留在本机，保存后清除草稿。学习备份只包含已保存笔记，不包含草稿。没有账号、广告或统计 SDK。

- **日历**：新版不再创建或同步课程日历。仅点“清除旧版提醒”时申请权限，并只移除旧版由欣语标记的事件。
- **文件**：只读取用户在系统文件选择器中选中的资料。导出备份由用户选择保存位置。
- **网络**：加载视频封面、公开的视频信息与视频流，以及主动打开的原站资料网页；这些服务按各自政策处理访问。视频流交给苹果系统播放器，不自动加载原站网页，不读取浏览器登录状态或 Cookie。临时播放地址不写入学习资料或备份。搜索在内置资料库中进行。
- **Bark**：只有主动配置后才向所填 Bark 服务器发送测试消息；自动提醒需主动连接定时服务并启用。定时服务收到接收密钥、课表提醒的时间、科目和班级，以便代发通知。配置保存在设备安全存储，不放入学习备份或 Git 仓库。

欣语不申请通讯录、定位、相机、麦克风、照片或自身远程通知权限。接收通知的 iPhone 16 需要为 Bark 开启通知权限。系统专注模式、网络和推送服务会影响到达，测试发送成功不等于手机已收到。

停用自动提醒须联网成功；卸载应用不会替你撤销服务中已安排的提醒。旧版日历提醒也需主动清除，以免重复。
