# 小花园的隐私约定 🤍

## 权限什么时候出现

| 能力 | 系统入口 | 请求时机与范围 |
| --- | --- | --- |
| 日历 | EventKit | 用户主动点击允许访问时；iOS 15–16 `requestAccess(to: .event)`，iOS 17+ `requestFullAccessToEvents` |
| 导入资料／备份 | 系统“文件”选择器 | 只读取主动选择的 security-scoped URL，导入后结束访问 |
| 外部网页 | Safari 系统控制器 | 仅用户点搜索或资料链接时打开；网站按自身规则处理网络数据 |

日历的系统授权范围可能覆盖全部日历，这是系统 API 的授权粒度。应用只查询自己保存的事件标识，写入／删除必须同时匹配**本机记录的专用日历 ID**与**本机私有标记**；不会通过同名日历认领数据，也不修改手动加入的事件。日历账户由使用者主动选择，不会静默换为本机账户。

不申请通讯录、定位、相机、麦克风、照片和本应用的通知权限；不创建后台常驻服务。上课提醒由系统日历处理。没有登录系统、广告、分析 SDK 或自建数据服务器。

## 数据在哪里

笔记、资料链接、调课记录与收藏保存在应用 Application Support 中，以原子写入保存。导入文件复制到应用私有附件目录。外部网页内容不会自动抓取成离线资料。

日历绑定与事件 ID 只保存在本机设置中，不写入应用导出的资料备份。系统 iCloud／设备备份行为取决于用户的 Apple 设置；本应用不承诺禁用系统级备份。

## 备份与删除

备份是可读 JSON，包含附件的 Base64 数据，**不是加密文件**。请保存在自己信任的位置，分享给别人前注意其中的个人笔记和课表。

导入备份会验证版本、路径和内容，同编号资料以本机为准。新恢复附件改名，避免覆盖本机文件。格式错误时不覆盖现有数据。当前学期设置、原始周课表和日历绑定不会被导入覆盖；调课记录会合并。

删除笔记只删除该条记录。移除资料不删除原网站或已经导入的本地文件，首版没有自动附件清理；卸载前请导出备份。外部事件或整本日历的系统恢复操作请在 Apple 日历中进行。
